# Rumbasha Backend

Backend API Rumbasha E-Learning Platform (Go, Gin, PostgreSQL).

Dokumentasi proyek ada di folder `docs/`:
- `BRD.md`: kebutuhan bisnis (v1.2)
- `ROADMAP.md`: jadwal dan urutan fitur
- `STATUS.md`: status fitur untuk laporan klien
- `KICKOFF.md`: panduan memulai dengan Claude Code

Panduan konvensi dan alur kerja ada di `CLAUDE.md`.

Setup lokal akan ditambahkan setelah slice 0 selesai (`docker compose up -d db`, `make migrate-up`, `make run`).
